# llmgateway-trends

Отслеживает, как распределяются запросы к модели **deepseek-v4-flash** между провайдерами
на [llmgateway.io](https://llmgateway.io/models/deepseek-v4-flash), и копит историю, чтобы
видеть кто растёт, а кто падает.

Источник — тот же эндпоинт, что питает блок «Provider Performance» на странице модели:
скользящее окно за 24 часа с числом запросов, ошибок, аптаймом, токенами в секунду и TTFT
по каждому провайдеру. Само окно наверху пересчитывается примерно раз в час, поэтому
динамику видно только если накапливать снимки — этим и занимается репозиторий.

## Как устроено

- `collect.py` — делает один снимок, дописывает строку в `history.jsonl`, при первом запуске
  вытягивает SVG-логотипы провайдеров в `logos.json`.
- `.github/workflows/collect.yml` — cron примерно раз в 5 минут, коммитит изменения обратно.
  Ничего разворачивать не нужно, сервер не требуется.
- `index.html` — дашборд. Открытый через GitHub Pages, читает `history.jsonl` напрямую.
- История прореживается автоматически: полное разрешение за последние 2 суток, раз в час
  до 30 дней, раз в 6 часов дальше. Год работы укладывается примерно в 3 МБ.

## Локальный запуск

```sh
python3 collect.py          # один снимок
python3 -m http.server 8000 # затем открыть http://127.0.0.1:8000/
```

Данные публичные — те же, что видит любой посетитель страницы модели.
